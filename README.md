A fast drop-in replacement for csv-reader 1.0.0. It reads broken CSV files — stray CRs, unterminated quotes, short and long rows — and returns exactly csv-reader 1.0.0's answers, 2.24x faster than the baseline on the local grade.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
